# 配色

| 用途           | 颜色值                 | 说明                        |
| -------------- | ---------------------- | --------------------------- |
| 主色           | `#2C75D1`              | 活力蓝，醒目不刺眼          |
| 主色 hover     | `#187bcd`<br />#1C3E60 | 深蓝一点，按钮/链接悬浮状态 |
| 强调色（次主） | `#00BFA6`              | 青绿色，有自然清新感        |
| 背景主色       | `#F5F9FF`              | 柔和灰白，干净，不压主图    |
| 顶部文字色     | `#ffffff`              | header 中的文字配白色最佳   |
| 正文文字色     | `#1f3a5f`              | 深蓝灰，柔和不刺眼          |
| 标题强调色     | `#FF9F45`              | 柑橘橙色，用于强调/按钮跳色 |
