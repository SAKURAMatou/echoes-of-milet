# 巡礼投稿弹窗交互设计

当前推荐预览：`index-v2.html`（轻盈版），样式 `style-v2.css`。保留 `index.html` / `style.css` 作为第一版对照，两版共用原有交互脚本。新版采用浅湖蓝主按钮、薄荷色选中态、淡紫地点背景、较轻遮罩和边框；不改变三步填写流程。

设计依据：公开端 docs 中的投稿需求与实施方案。采用用户确认的三步填写、最后预览确认。

视觉参考：src/views/milet/MiletPilgrimageView.vue 和 src/components/milet/pilgrimage/PilgrimageSpotDetailPanel.vue。延续浅蓝背景、青绿按钮、淡紫注记、衬线标题及细边框，不引入外部设计系统。

入口：index-v2.html。使用本地 HTTP 服务预览。默认打开新增地点；关闭后可从右侧示例地点打开纠正弹窗。顶部可切换中文/日文，语言切换先关闭弹窗；弹窗手机宽度下全屏。示例地点不是正式巡礼事实。

包含：必填校验、纠错项目多选、地图链接/地址兜底、来源说明、照片本地选择/拖放/移除、照片用途、昵称/邮箱、预览、确认声明、演示提交结果和暂时关闭确认。两种投稿分别保留当页草稿。

边界：纯设计原型。图片仅用本地 Object URL 预览，未实现 WebP Worker、R2 上传、Turnstile 或后台提交，不产生外部写入。验证码为明确标识的演示控件。正式版需采用实施文档中的安全流程。背景为简化上下文，不是地图功能实现。未新增生产 Vue 组件。

样式统一：参照现有巡礼详情与区域筛选组件，按钮、输入框、地点卡片、上传区和图片统一 8px 圆角；提示错误使用 6px，弹窗容器使用 16px（手机投稿弹窗保持全屏直角）。关闭按钮改为与详情面板一致的方形圆角按钮；步骤数字与成功标记保留圆形。间距统一到 4px 倍数，主要采用 8 / 16 / 24 / 32px，主按钮沿用详情导航按钮的浅蓝配色。


真实 Vue 组件验证页：启动公开端 Vite 后访问 `/designs/pilgrimage-submissions/component-preview.html`。可查看新增/纠正、日文及 Web Worker 转码结果；此页不连接生产投稿，不能代替 Cloudflare 集成验收。
